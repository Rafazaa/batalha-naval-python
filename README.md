# batalha-naval-python
Um jogo de termninal que o usuario digita um numero de 4 a 6 para criar o mapa 4x4 ou 6x6 e depois tem que achar os inimigos nos eixos (x, y)


## Como Inicializar
No teu terminal (ou usando "`Ctrl + `" no VS Code), executa:

"`py batalha-naval.py`"
